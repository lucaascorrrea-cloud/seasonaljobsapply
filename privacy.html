Seasonal Jobs Apply · Last updated: August 3, 2026

Seasonal Jobs Apply does not collect, store, or share your personal data on any external server. All data stays locally on your device.

3. Data Protection Mechanisms

All sensitive data is protected using the following mechanisms:
  • Local storage only: All user data — including résumé PDFs, cover letters, application history, profile settings, and Gmail tokens — is stored exclusively in chrome.storage.local, which is sandboxed to the extension and inaccessible to any other application or website.
  • No external transmission: No personal data is transmitted to any server owned or operated by Seasonal Jobs Apply. The only external communications are directly to Google APIs (Gmail, Drive, People) and Telegram API, using the user's own authenticated tokens.
  • OAuth 2.0 security: Authentication is handled entirely by Google's OAuth 2.0 system via the Chrome Identity API. No passwords are stored. Tokens are managed by Chrome and automatically refreshed and revoked by Google.
  • Minimal scope principle: The extension requests only the minimum scopes necessary for its features. gmail.readonly is used only to read thread message counts — email content is never read, displayed, or stored.
  • Encrypted transmission: All API communications use HTTPS/TLS encryption.
  • No third-party tracking: The extension contains no analytics, advertising SDKs, or tracking pixels of any kind.
  • Drive backup encryption: Backup files stored in Google Drive are protected by Google's own security infrastructure and accessible only by the authenticated user.

4. Gmail API Usage — Detailed

gmail.send scope: Used exclusively to send job application emails via the Gmail API on behalf of the user. Each email is sent only when the user explicitly clicks the "Send Application" button. The email content, recipient, subject, and résumé attachment are composed by the user within the extension. No automated or bulk sending occurs without user action.

gmail.readonly scope: Used exclusively to check whether a recruiter has replied to a previously sent application email. The extension reads only the message count of specific Gmail threads initiated by the user. At no point does the extension read, store, display, or transmit the content, subject, sender, or any other field of any email — including the application emails sent. Only thread metadata (number of messages) is accessed.

Our use of Gmail API data complies with the Google API Services User Data Policy, including the Limited Use requirements.

5. Google Drive API Usage

The drive.file scope is used exclusively to create and read backup files in a folder named "SeasonalJobsAutoApply" in the user's own Google Drive. The extension can only access files it creates — it cannot read any other files in the user's Drive.

6. Data Retention and Deletion

Since all data is stored locally on the user's device, retention is fully controlled by the user:

  • Uninstalling the extension from Chrome permanently deletes all stored data
  • Users can clear extension storage via Chrome's "Clear site data" feature
  • Drive backup files can be deleted directly from Google Drive
  • Gmail access can be revoked at Google Account Permissions

7. Data Sharing

We do not sell, rent, trade, or share user data with any third party. The only external services the extension communicates with are:

  • Google Gmail API — to send emails and detect replies
  • Google Drive API — for backup
  • Google People API — to display account profile
  • Telegram API — for notifications (only if configured by the user)
  • flag.dol.gov — to check official job application status

9. Children's Privacy

This extension is not directed at children under 13. We do not knowingly collect information from children.

3. Mecanismos de Proteção de Dados

Todos os dados sensíveis são protegidos pelos seguintes mecanismos:
  • Armazenamento local: Todos os dados — incluindo PDFs de currículo, histórico de candidaturas, configurações e tokens do Gmail — são armazenados exclusivamente no chrome.storage.local, isolado da extensão e inacessível a outros aplicativos.
  • Sem transmissão externa: Nenhum dado pessoal é transmitido a servidores de propriedade do Seasonal Jobs Apply. As únicas comunicações externas são diretamente para as APIs do Google e Telegram, usando os tokens autenticados do próprio usuário.
  • Segurança OAuth 2.0: A autenticação é feita pelo sistema OAuth 2.0 do Google via Chrome Identity API. Nenhuma senha é armazenada.
  • Princípio do mínimo privilégio: A extensão solicita apenas os escopos mínimos necessários. O escopo gmail.readonly é usado apenas para verificar a contagem de mensagens de threads — o conteúdo dos e-mails nunca é lido ou armazenado.
  • Transmissão criptografada: Todas as comunicações com APIs usam HTTPS/TLS.
  • Sem rastreamento: A extensão não contém analytics, SDKs de publicidade ou pixels de rastreamento.

4. Uso da API do Gmail — Detalhado

Escopo gmail.send: Usado exclusivamente para enviar e-mails de candidatura via API do Gmail. Cada e-mail é enviado somente quando o usuário clica em "Enviar candidatura". Não há envio automático ou em massa sem ação do usuário.

Escopo gmail.readonly: Usado exclusivamente para verificar se um recrutador respondeu a um e-mail de candidatura enviado anteriormente. A extensão lê apenas a contagem de mensagens de threads específicas. Em nenhum momento o conteúdo, assunto, remetente ou qualquer outro campo de e-mail é lido, armazenado ou transmitido.

Nosso uso está em conformidade com a Política de Dados do Usuário dos Serviços de API do Google.

5. Retenção e Exclusão de Dados

  • Desinstalar a extensão exclui permanentemente todos os dados armazenados
  • O acesso ao Gmail pode ser revogado em Permissões da Conta Google
  • Arquivos de backup podem ser excluídos diretamente do Google Drive

6. Compartilhamento de Dados

Não vendemos, alugamos nem compartilhamos dados com terceiros. Os únicos serviços externos são: API do Gmail, API do Drive, API do Google People, API do Telegram e flag.dol.gov.
